Escenario de caldera

Demostración local del sensor virtual que estima el caudal de vapor principal ZZQBCHLL.AV_0#. Carga una fila preparada o prueba un escenario sintético.

¿Qué representa la predicción?

Es una estimación consultiva del caudal que produciría la ecuación Ridge a partir de otras señales. Puede servir para contrastar el flujo cuando las entradas estén disponibles y una medición independiente permita revisar el resultado. El archivo no necesita incluir el objetivo: ninguna entrada es el propio caudal ni una transformación suya.

Evaluar una entrada

Se requieren 17 columnas con los nombres originales del modelo: 15 señales actuales y dos presiones registradas 30 segundos antes. La API no calcula ese historial; el archivo debe traerlo ya preparado.

Descargar plantilla CSV

El escenario sintético coloca la mediana de ajuste de cada señal; no es una lectura real ni una recomendación operativa.

CSV: encabezados originales y exactamente una fila de datos. JSON: un objeto con esos mismos 17 nombres. Tamaño máximo: 100 KB. Las filas adicionales se rechazan.

Límites para interpretar

  • Las dos presiones rezagadas requieren historia previa de 30 segundos en el sistema que prepare el archivo.
  • El rango aceptado es el mínimo y máximo observados en el ajuste, no una banda de seguridad. Un valor operativo válido fuera de ese rango también será rechazado.
  • Los sensores, sus unidades y la independencia instrumental no están certificados. Una predicción por sí sola no diagnostica fallas ni demuestra ahorro de combustible.
  • Es una demostración histórica, no un sistema de control ni una alarma. La evaluación del modelo no es independiente y no incluye el quinto día.
